Q1. What is Django?
Django is a high-level Python web framework used to develop secure, 
scalable, and maintainable web applications quickly. 
It follows the MVT (Model-View-Template) architecture.


Q2. What is the difference between a Django project and a Django app?
A Django project is the complete web application containing configuration and settings. 
A Django app is a modular component that performs a specific function. 
For example, realestate is our project and properties is our app.


Q3. What is a virtual environment in Python, and why do we use it?
A virtual environment is an isolated Python environment used to manage 
project-specific packages and dependencies without affecting other Python projects.


Q4. What are Django migrations?
Migrations are Django's way of tracking and applying changes to database schemas. 
makemigrations creates migration files, while migrate applies those changes to the database.


Q5. What is Django Admin, and what is a superuser?
Django Admin is a built-in interface for managing application data. 
A superuser is an administrator account with full permissions to manage the Django admin site.
